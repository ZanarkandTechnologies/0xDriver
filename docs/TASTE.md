# Taste

## Core Direction

- Operational research tooling over consumer polish.
- Dense, legible, evidence-first surfaces.
- Serious technical tone with clear diagrams and compact labels.
- Prefer trajectory overlays, latency tables, and failure-case panels over
  decorative visuals.

## Demo Bias

- The demo should show the actual Waymo scene, model intent, predicted path,
  smoothed path, and metric outcome.
- Avoid pretending the first release is a production autonomous driving system.
- Make uncertainty visible when it changes behavior.

## Project Overrides

- If a UI is later added, keep it compact and inspection-oriented.
- If a slide deck is created, lead with the architecture thesis and evidence,
  not a marketing-style hero.
